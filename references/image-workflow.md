# 模型执行、可复用提示词与验收

摄影 skill 由宿主助手读取，再组织参数并调用 image 模型；不是把 SKILL.md 上传给图像模型后让其自行调用工具。不要承诺第三方模型一定能执行文件或严格复现摄影数值。

## 输入与模式

区分新图、参考生成、编辑。参考图逐张注明：身份、服装、姿势、构图、光线或风格；不要把风格参考中的人物也无意加入画面。编辑明确目标图与不变量。用户只要求提示词时在此停止，不自动生图。

使用当前环境内置 image 生图工具。工具若以 `image_gen.imagegen` 暴露，可接受 prompt、transparent_background，以及二选一的 referenced_image_paths 或 num_last_images_to_include。具体名称可能变化，先检查当前工具定义。不要自行添加 model、quality、size、seed、mask 或 output_path 等未支持参数；需要画幅时写入提示词并核验结果。真实透明背景用支持的透明参数，而非只写“白色背景”。

所有引用图片必须能提供给工具：本地图片先 view_image 检查，再用路径引用；会话图片用覆盖所有目标的最小近期图片数量，最高遵守工具限额。两种引用机制不能同时传。若任何必要图片无法引用，请用户重新附图。无参考新图省略引用参数。不要为正常生图偷偷转到付费 API/CLI，也不索取聊天中的密钥。

如果环境另有内置 imagegen skill，实际执行同时遵循其当前工具与输出规范。本 skill 自身保留上述可移植的行为，不依赖固定本地路径。

## 决策记录模板

内部保存：目的；主体/身份不变量；环境；机位高度/距离/朝向；景别/画幅；构图；姿势/表情；光源几何；焦点/景深；运动；色彩/材质/后期；图内文字；参考角色；必须保留/避免；覆盖项状态。

用户未指定且不影响结果的项可不展开。明确相机是在画外；除非用户要幕后图，不生成画面中多余的摄影师、相机或灯架。

## 提示词模板

```text
任务：生成摄影照片 / 编辑所提供目标图。
用途与主体：[用户要求；人数；身份或产品不变量]。
场景：[地点、背景、时段、道具及前中后景]。
机位和构图：[相机相对位置、朝向、景别、画幅、主体占比、留白]。
人物：[身体朝向、承重/动作、手的任务、头部朝向、视线、表情]。
光线：[实际来源、画面方向、高度、柔硬、暗部细节、轮廓、色温]。
光学效果：[清晰范围、透视、背景可读程度、运动效果；必要时辅助焦距]。
质感和色彩：[真实材质、肤色/商品色、调色与颗粒意图]。
参考与约束：[每张图角色；编辑只改什么；必须保持什么；准确文字]。
```

不用把清单所有栏目机械塞入 prompt。删掉无关项目及矛盾。优先可见关系，避免“电影感、顶级、8K、大师作品”等空泛词替代设计。中文或英文均可，不声称英文必然更好。

## 原创调用例子

### 窗边半身人像

用户仅指定“窗边、自然、半身人像”时，可采取以下可更改的构思，不擅自增添其身份或服装：

```text
生成一张自然的人像摄影照片，保留用户指定的主体与服装。室内窗边，背景简洁但仍能辨认房间。竖向半身构图，相机在人物眼睛高度，保持自然的面部比例。躯干稍侧转，头轻转向镜头，双肩放松，一只手自然搭在窗台上，手腕不僵硬，表情平静。画面左侧的大窗户提供柔和侧光，右脸略暗但保留细节，眼中有与窗户方向一致的柔和眼神光。眼睛清晰，背景适度柔化，皮肤保留真实纹理。不要额外添加人物、摄影器材、文字或水印。
```

### 全身时尚

```text
全身时尚摄影，沿用用户的人物、服装与场景。相机在腰部高度，距离足够远，镜头轻微向上，强调姿态而不夸大脚部；人物从头到鞋完整入镜，脚下留出空间。重心在后腿，前腿放松，肩与骨盆略有不同转向，一只手轻搭衣服侧缝，另一只手放松。主光来自画面右侧上方，形成清晰但可信的硬影，背景与人物有明度分离，衣料织纹可见，面部与身体保持同一身份和自然比例。
```

### 只改灯光的编辑

```text
编辑目标图，只把主要照明改为画面左侧大窗户的柔和侧光。保持人物面部结构、年龄、肤色、体型、服装、姿势、相机位置、画幅和背景物体布局。联动调整与新光源对应的投影、眼神光和表面反射，保留原有材质。不要增加灯具或改变构图。
```

### 产品

```text
以用户产品参考为真实形状和标签依据，生成干净的商业产品照片。相机在产品中部高度，三分之四侧视，完整展示外形与主要标签。产品立于指定表面，有可信接触阴影；大面积柔光从画面左上方照入，右侧较弱反射补光，控制亮部以清楚读出材质。产品和标签清晰，背景简洁。逐字保留用户指定文字，不添加品牌或改变结构。
```

## 验收和迭代

先检查硬限制，再检查物理关系，再检查美感。必须实际查看可访问返回图；若工具仅返回无法查看的结果，说明视觉验收未完成。

- 主体数量、身份、服装、商品形状和文字是否正确？
- 画幅、景别、机位、背景和用户留白是否实现？
- 手脚归属、关节、承重、接触、眼睛/牙齿及遮挡是否可信？
- 阴影、反射、眼神光与光源是否协调？
- 焦点、景深、运动效果和材质是否支持用途？
- 编辑或系列不变量是否漂移？

每次修正保留完整不变量，只改变导致具体问题的因素。系列一次一张按所需张数调用；不把“4张图片”写在单张提示词里导致拼贴，除非用户要拼贴。没有实际生成则不声称验收通过。模型可能不能精确保持身份、数量或文字，不能靠文字自评分取代看图。

输出遵循用户命名和目录；没有指定时用当前工作区 deliverables/outputs 约定。保留真实输出，不覆盖已有文件，展示可访问图片和最终路径。生成样图测试涉及图像调用成本，只有用户要求样图或实际生图时才执行；创建 skill 本身做结构与行为检查即可。
