# 人物和光线的联合设计

## 人物从支撑到表情

先确认动作、体型与服装保留要求。把姿势拆成支撑点→脚→腿→骨盆→脊柱→肩→肘腕→手→头→视线→表情。不是每次都修改所有部位；只把决定画面和容易出错的关系写入提示词。

- 站姿：明确承重脚，非承重腿可放松。肩与骨盆的转向可以不同，但避免不可能的扭转。正面方正或不对称都可用，取决于用户想表达的感受。
- 坐姿：椅子必须实际承重，双脚位置可信；臀部、座面和背部关系明确。坐椅前部有利于伸展，但不是所有坐姿都需要挺胸。
- 躺姿：说明承重表面、头和手的位置、重力作用。避免头发、衣服和身体同时漂浮。
- 走动：决定步态瞬间与前后脚，手臂与身体运动协调，不能把静态交叉腿和奔跑同时硬拼。
- 手部：让手有清楚任务，如轻握杯柄、搭在椅背或放松垂下。指定接触点、遮挡及力度；触脸时不要无意压出脸部变形。自然遮挡不等于必须显示十个手指。
- 头与下巴：头部转向、俯仰、侧倾分开；相机、胸口、鼻尖和眼睛不必全部朝同一方向。注意过度抬头或低头与眼神关系。
- 表情：以可见动作描述，例“嘴角轻微上扬、眉间放松、眼神看向镜头”；不把“开心”仅转为夸张露齿。
- 双人：各自站位、相互视线、距离和手的归属明确。拥抱时身体和手臂不能互相穿透。
- 群体：人物层次、脸部遮挡、清晰范围和视线关系明确，不能只说“大家排好”。
- 服装妆发：衣物的紧松、材质、褶皱和头发遮脸程度会影响轮廓。保持参考指定，不擅自美容重塑。

不同性别不自动对应强势或柔美姿势；按人物和用户意图选择。实拍给短而可执行的指令，尊重身体活动范围。新生儿、孕期或复杂运动实拍涉及专业摆放时，不从生图想象推断可安全执行的操作。

## 光源的六个变量

每个主要光源记录：来源、主体哪一侧、相对高度、大小/距离、柔硬、色温。先约定“画面左/右”以相机看到的图像为准；“人物左/右”则明确说明，不能交替使用。

主光建立造型；补光调暗部；负补光用遮挡/吸光增加暗部；轮廓光分离边缘；背景光决定背景亮度；台灯/霓虹等实际可见光源要与效果一致。并非每幅图都需要全部灯。

光源相对角尺寸大通常影缘柔，小通常影缘硬。光源移动也改变衰减、覆盖、背景受光和反射；不能只改“柔和”一词而忽略距离。近距离小布光区可能让走动人物曝光变化明显；全身动态拍摄要考虑头到脚的覆盖。

## 布光选择

| 模式 | 需描述的几何关系 | 观察标准 |
|---|---|---|
| 蝴蝶光 | 主光靠近相机轴线上方 | 鼻下小阴影、眼睛仍有眼神光 |
| 环形光 | 主光稍偏侧且较高 | 鼻侧短阴影，通常与脸颊阴影分开 |
| 伦勃朗光 | 侧上方主光与面部朝向配合 | 暗侧脸颊有小亮区，而非凭标签生成任意斑块 |
| 分割光 | 侧向光配合面部位置 | 一侧亮另一侧暗，仍可按需要补光 |
| 宽面/窄面 | 面部转向决定相机所见宽侧或窄侧受光 | 二者与柔硬、灯数量独立 |
| 夹光 | 上方主光加下方补光/反射 | 眼窝可读、鼻下影减轻，下方不能无意变成主光 |
| 逆光/轮廓 | 光来自主体后方 | 发丝或边缘分离，正面是否补光取决于用途 |
| 窗光 | 窗户大小、方向及人与窗的距离 | 影向与窗户一致，背景亮度有依据 |
| 硬光时尚 | 小角尺寸光源，精确投影 | 可保留硬影与肤质，不自动磨成柔光 |

这些模式是起点；面部、相机和光的位置要一起调整。不要把固定 45° 或固定光比当作万能方案。

## 反差、曝光和色温

高调使用整体较亮的场景但保留高光细节；低调使用整体较暗的场景但关键主体应可读。柔硬与反差分开决定。描述光比必须说明是主光与补光独立读数，还是脸部亮侧与暗侧总照度；不混用两个定义。生图通常用“暗侧保留细节但显著较暗”比未定义的 4:1 更直接。

混合光要分配来源和颜色，比如暖色台灯在后景、冷色窗光照脸，而不是全图“既暖又冷”。投影方向、眼神光数量、金属反射和地面接触阴影共同检查。玻璃眼镜避免不必要的遮眼反光，但需要保留可信的镜片材质。

## 联动排错

脸部比例不合意→先检查拍摄距离与机位，再看头部姿势；眼窝太暗→检查主光高度、面部仰俯和补光；身体显僵硬→检查支撑和关节而不是只加“自然”；手抢画面→检查近大远小、手的姿态和亮度；背景抢眼→调整背景受光/构图/清晰度；轮廓不清→调整人物与背景距离、明度差或轮廓光，不一定新增灯。
