# 摄影决策

本文件是公开教程要点与通用摄影知识的原创决策综合。来源支持各主题，不把整个文件归为任何一篇文章的摘要。

## 意图、场景和构图

确定主体是谁、观众先看哪里、想感到什么。选择背景的亮度、颜色、清晰度和信息量，使其支持用途。环境人像需要能辨认的环境；证件或产品目录优先可读性；叙事画面允许次级主体和对比。先布置背景与空间关系，再安排人物，避免所有风格都套用奶油虚化。

画幅以用户用途为准；没有说明时依主体及展示方式选择，并简短说明假设。负空间的方位来自文案版位或人物视线，不能随机规定。检查画面边缘是否有切断的手脚、穿过头部的线、极亮斑点、无意出现的物品。裁切一般避开关节和指尖，但可以为明确的特写意图做例外。

三分、对称、引导线、框景、重复和对角线分别是组织注意力的选择。用前中后景制造深度；用相对大小和遮挡建立空间；用人物距离与朝向表达关系。居中可表现稳定或正面凝视，偏置可容纳环境或方向感。避免在一个提示词里同时要求“极简居中”和“复杂多主体对角线布局”。

## 机位：位置和朝向分开描述

以主体为参照，给出相机高度、到主体的距离、站在主体哪一侧、镜头指向哪里。高度低不一定意味着大幅仰拍；高机位不一定是垂直顶视。

| 选择 | 可见结果与适配 | 检查 |
|---|---|---|
| 眼平、水平 | 自然接触，人物或物体关系平稳 | 不把它理解成固定胸像 |
| 略高、轻俯 | 看见更多上表面，脸在近处 | 额头/头身比是否被过度强调 |
| 略低、轻仰 | 强调高度、腿部、上升线条 | 下巴、鼻孔、垂直线是否符合意图 |
| 垂直顶视 | 平铺、几何关系、环境图案 | 明确是真顶视，不能仍看到正面全脸 |
| 地面/极低 | 强烈前景和尺度 | 近处肢体、鞋和物体是否过大 |
| 正面/三分之四/侧面/背面 | 改变轮廓与可见表面 | 头、躯干和相机朝向分别指定 |
| 肩后/主观 | 表达关系或观察视角 | 前景肩部来自哪个人，遮挡是否过量 |
| 横滚倾斜 | 动感或不安 | 不把俯仰与 Dutch angle 混淆 |

不要默认低机位等于权威、高机位等于脆弱；它们只是可能的视觉读法。人物表情、场景、尺度和文化背景共同决定效果。

## 镜头、距离和景深

用全画幅等效描述焦距，避免传感器差异造成混淆。以下是构思范围，非硬规则：广角约 16—35mm 适合强调环境和近处尺度；标准约 40—60mm 适合均衡关系；中长焦约 70—135mm 常用于在更远距离拍摄人像并简化取景；更长焦适合远处主体或小范围取景。

透视由相机位置决定。固定相机位置换焦距并裁成相同画面，不应声称面部透视必然改变。为了相同主体大小换长焦，通常要后退，新的观察距离才使前后大小关系变化。广角从近处拍脸会强化近处五官，并非一切广角人像都有同等变形。

描述景深应明确“近眼清晰、远眼也可辨认”“全组人物清晰”“产品标签到外缘清晰”或“背景环境仍能辨认”。浅景深不等于主体所有位置都清晰；微距尤其要权衡景深。散景大小受光圈、焦距、距离及背景距离共同影响。生图优先写出清晰范围，f 值仅作辅助。

## 曝光和运动

真实拍摄：先满足景深及运动要求，再选曝光组合。光圈影响景深和进光，快门影响环境曝光及运动表现，ISO 影响信号放大与可用画质；曝光不能只靠 ISO 替代光线设计。直方图与高光警示辅助判断，不把所有场景都强行拉成中灰。白平衡匹配光源或有意创造色温差。

人物静止可单次对焦；主体移动应考虑连续对焦和连拍。浅景深时对焦后大幅重新构图可能使眼睛离开焦平面。快门应依据动作、焦距、防抖和输出大小选择，不给一个适用于全部拍摄的万能数值。生图把快门意图转成“冻结发丝/水滴”或“主体清晰、背景方向性拖影”。

闪光实拍需注意同步速度、HSS 功率损失、回电及闪光持续时间；不能把快门速度直接当作冻结闪光主体运动的唯一因素。生图要求可信的运动状态与光源关系，不虚构硬件实际运行。

## 色彩、材质和后期

配色服务用途：统一色相可安静，冷暖或互补对比可分离主体。保留衣服和产品的指定颜色；肤色不应被无意污染。混合色温先确认是需要的气氛还是问题。黑白关注明度分离，不能只去掉颜色而忽略背景与服装同灰。

材质需写出不同的反射方式：金属以环境映射为主，玻璃透射并反射，布料保留织物与褶皱，皮肤有细微纹理和自然高光。局部明暗、颜色、锐化和颗粒应一致，不把“专业”自动转换成磨皮、过锐、过饱和或大幅 HDR。

## 题材适配

| 题材 | 必须额外决定 |
|---|---|
| 产品 | 形状、标签/文字、色彩准确性、拍摄表面、反射、边缘光、接触阴影；商品真实参考优先 |
| 食物 | 新鲜质感、盘沿、餐具尺度、适合的俯拍或侧拍、蒸汽是否真实可见 |
| 建筑 | 垂直线、消失点、比例、机位与空间关系；超广角畸变是否有意 |
| 风光 | 地平线、天气、时间、前景距离、远景层次、景深；不凭空换地貌 |
| 街头/纪实 | 动作瞬间、环境上下文、真实感；生成画面不得冒称真实新闻照片 |
| 运动 | 动作阶段、重心、支撑、轨迹、冻结或拖影、运动留白 |
| 微距 | 尺度、焦平面、极浅景深、表面细节；主体科学结构不确定时查证 |
| 夜景 | 实际可见灯源、曝光平衡、噪点/模糊意图、灯光反射和色温 |
| 系列 | 不变量及每张唯一变化，跨图主体外观和环境一致性 |

专业细节若超出这些基本决策，在 sources.md 的对应站点继续检索，不凭覆盖清单假装已有完整教程。
